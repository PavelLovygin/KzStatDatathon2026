# KzStatDatathon2026

Анализ удовлетворённости качеством медицинской помощи в Казахстане по синтетическим
микроданным БНС (StatDatathon 2026).

**Описание проекта:** [Google Doc](https://docs.google.com/document/d/1fPLA4B1E3W7SnuLMssNb-a-S6bjIgwZxeL86jrlANh4/edit?usp=sharing)

## Файлы

| Файл | Что делает |
|---|---|
| `00_build_dataset.Rmd` | Собирает формы D002 и D008 и региональные показатели за 2021–2024 годы в одну таблицу с подписями столбцов |
| `01_eda.Rmd` | Эксплораторный анализ на объединённом датасете: распределения, социальные различия, карты, ICC |
| `*.html` | Готовые отчёты — их можно открыть в браузере без запуска кода |

## Данные

В git не хранится только `Data/Original/` — исходные таблицы датасета. Всё остальное, включая
объединённый датасет, лежит в репозитории, поэтому `01_eda.Rmd` запускается сразу после
клонирования.

```text
Data/
├── Original/                      ← сюда копируется папка с данными датасета (не в git)
│   ├── d002/2021…2024/            subject.csv, ocenka.csv
│   ├── d008/2021…2024/            kontr_k.csv
│   ├── documentation/             бланки анкет
│   └── …                          остальные формы не используются, но могут лежать здесь
├── health_quality_dataset.rds     объединённый датасет с подписями столбцов
├── health_quality_dataset.csv     он же в CSV
├── health_quality_dictionary.csv  словарь столбцов
├── health_regions.csv             региональные показатели здравоохранения
├── kz_regions_osm.csv             контуры регионов для карт
└── regional_sources/              первоисточники региональных показателей: БНС, «Талдау»
```

Файлы `health_quality_*` создаёт `00_build_dataset.Rmd`.

## Как запустить

- **Только анализ:** откройте `01_eda.Rmd` в RStudio и нажмите **Knit**.
- **Пересобрать датасет:** скопируйте **содержимое** папки с данными датасета (папки `d002`,
  `d008`, `documentation` и т. д.) в `Data/Original/` — должен получиться путь вида
  `Data/Original/d002/2021/subject.csv`, — затем запустите `00_build_dataset.Rmd`.

  Если исходных таблиц нет, скрипт сразу остановится и подскажет, какого файла не хватает.

Нужные пакеты: `tidyverse`, `scales`, `nlme`, `ordinal`, `rmarkdown`.

## Объединённый датасет

```r
df <- readRDS("Data/health_quality_dataset.rds")
View(df)   # под именами столбцов видны подписи: вопрос, источник по годам, коды ответов
```

Одна строка — один респондент анкеты D002 в одном году: 47 771 строка, 313 столбцов.

- Код 89 («затрудняюсь ответить») сохранён — перед расчётами его нужно заменить на `NA`.
- Респонденты младше 15 лет оставлены и отмечены флагом `under15`.
- Полный словарь столбцов — `Data/health_quality_dictionary.csv`.
